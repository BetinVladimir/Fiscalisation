# MiniPOS Web working-language review

Date: 2026-10-01. Status: **structurally complete, linguistic review open**.

The 52 working UI keys are present and non-empty in all 25 EU/RU locales. Eighteen established POS terms come from the checked-in BeeMiniPOS dictionary. Thirty-four MiniPOS Web-specific strings were generated by the local Ollama `qwen3.5:9b-mlx` model or maintained as EN/BG/RU overrides in `scripts/sync-work-translations.mjs`. `src/ui/workExtras.generated.json` stores the output and `npm run translations:sync-work` reproduces the standalone web dictionary. No runtime fallback to English is used for these keys.

`tests/workTranslations.test.ts` validates the 25×52 structure. `e2e/work-language.spec.ts` switches through all 25 languages on a 360 px working screen, verifies navigation/sale labels and no horizontal overflow, then checks the management forms in EN/BG/RU/DE/FR. The long Slovak menu label initially caused horizontal overflow; the shared Paper selector now has a bounded width and wraps. Both E2E tests pass.

This does **not** certify semantic accuracy. Spot review found likely mistranslations in inherited Irish and Maltese POS terms and in new model output. For example, Irish `checkoutFiscal` was generated as `Óstáil agus fisiciúil`; neither this nor the alternate local model's `Íocaíocht agus fiosrú` reliably describes issuing a fiscal receipt. Inherited Irish `sales` and `quantity` also look suspect. Financial actions, offline reconciliation warnings, shift terminology, and accessibility labels require bilingual editorial review in every locale before release. The UI-optimization translation gate remains open. Technical API error strings and diagnostic JSON also need a localized presentation strategy.

## Offline operations labels

The read-only outbox adds nine strings per locale, so the current structural inventory is **25 × 51**. EN/BG/RU are maintained explicitly; the other languages were first generated by local Ollama. A spot comparison with a second local model showed that automatic output can change the meaning of fiscal terms, especially in Irish. Obvious German and Croatian wording errors were edited in `src/ui/workExtras.generated.json`, then regenerated. `tests/workTranslations.test.ts` verifies structure and `e2e/work-language.spec.ts` verifies the new navigation label across all 25 languages. Neither test certifies linguistic correctness. The new uncertain-result and pending-sync warnings are critical and require bilingual review before release.

The session-recovery state adds `sessionUnavailable`, bringing the current dictionary to **25 × 52** keys. E2E confirms BG/RU switching on that screen; the structure test covers all languages. Spot checks of GA/MT still require bilingual review, and the translation gate remains open.
