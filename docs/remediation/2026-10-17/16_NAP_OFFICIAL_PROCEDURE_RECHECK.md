# Повторная проверка процедуры НАП

Дата обращения: 2026-10-18. Это подготовка dossier, не подтверждение соответствия MiniPOS.

Официальная [страница НАП о декларировании](https://nra.bg/wps/portal/nra/fiskalni-ustroystva-supto-i-e-magazini/supto/page.deklarirane-supto) описывает включение в публичный список через декларацию производителя/распространителя. Она указывает приложение 29 либо применимый специальный порядок 52а1, декларацию по приложению 30, сведения по приложению 31, руководство и описание реализации требований. Для SaaS требуется описание локальных компонентов, коммуникации с фискальными устройствами и местонахождения БД; при локальной БД — соответствующая документация и извлечение данных. Подача электронная с КЭП; версия и изменения требуют отдельного сопровождения.

Для нашего гибридного контура подготовить: версионированный перечень MiniPOS/backend/S3/BlueCash, схему облачных и локальных БД, каналы/порты, словарь таблиц, исходники и исполняемый extractor, руководство, матрицу «требование → реализация → тест → evidence». Наличие SQLite на S3 необходимо явно описать. Эти deliverables сверить с полным применимым нормативным текстом и официальным self-assessment checklist; страница процедуры сама по себе не доказывает полноту редакции законодательства на дату выпуска.

[Страница НАП для пользователей](https://nra.bg/wps/portal/nra/fiskalni-ustroystva-supto-i-e-magazini/supto/page.Informacia-za-potrebiteli-na-SUPTO) отдельно описывает выбор использования соответствующего СУПТО и предоставление сведений пользователем. Решение о конкретной применимости, заявителе и модели распространения остаётся внешним gate. Декларация, включение в список, фискальное устройство и банковский HIL не объединяются в одно программное PASS.
