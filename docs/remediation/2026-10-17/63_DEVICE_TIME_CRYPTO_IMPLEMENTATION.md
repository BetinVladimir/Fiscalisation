# Device time proof and verifier: integrated crypto foundation

The accepted [contract60](60_DEVICE_TIME_PROOF_VERIFIER_CONTRACT.md) is implemented as DeviceTimeAnchorCoordinator, a purpose-constrained DeviceIdentity request signer and strict root response verifier. Request17fields bind boot/request nonce, checked sequence, actual installed scope and actual SPKI/kid. The immutable expected exchange retains private ticket/request hash/trust ownership. Root22field responses use strict canonical int64 JSON, purpose-separated singlehash and minimally encoded P256 DER. Unsigned failures preserve pending authority; matching valid responses enter the interval core only through a private permit. No generic time setter or raw signing API is exposed.

Production-contract compilation excludes the host root override and synthetic core permit factory. Native checks include hostile signed fields, low/high-S root DER, malformed framing/DER, stale/replayed response, replacement after prepared return, deadline expiry, DRBG signing failure, default missing root/no automatic boot and explicit trusted lifecycle calls. Two signer threads test serialization, without a pause barrier inside signature/verification.

## Explicit remaining gates

No runtime provider, startup entropy adapter, server AuthorityClock health monitor, real root issuer, bootstrap route/relay or existing execution/local-token time migration is enabled. Coordinator trusted boot/binding/invalidate calls were tested directly. Actual installer/key/trust lifecycle callbacks are not wired; installed A→B→A without those hooks is not covered. Key/trust rotation, real monotonic drift/sleep policy, standard TLS/GATT, physical HIL and applicable НАП review remain OPEN. Production compiled root trust is immutable; override exists only under the explicit crypto-host-test macro. Device private keys remain ESP32-S3 NVS; ATECC608 is unused.
