## Как читать статусы

| Статус | Значение |
| --- | --- |
| SOURCE_PRESENT | Найдена реализация; работоспособность не доказана одним чтением |
| REPORTED_PASS | Есть предыдущий отчёт с ограниченным scope; в этом ревью повторно не запускался |
| VERIFIED_PASS | Выполнена конкретная проверка текущего среза, приложены команда/результат/хеши |
| VERIFIED_FAIL | Воспроизведён провал текущей проверки |
| IMPLEMENTATION_REQUIRED | В согласованном объёме есть отсутствующая/незавершённая реализация |
| NOT_RUN / DEMO_PENDING | В соответствующем окружении не проверено |
| HIL_PENDING / EXTERNAL_PENDING | Нужны физическое устройство или внешнее подтверждение |

Слово «работает» без среды, версии, сценария и доказательства недопустимо. Успешная генерация приложения не доказывает запуск на Android/iOS; mock-принтер не доказывает фискальный чек; подтверждение эквайринга не доказывает фискализацию.
