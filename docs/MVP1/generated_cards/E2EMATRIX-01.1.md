Для кода запустить реальный native runtime/tests subprocess либо импортировать production Python module. Автостатус только TESTED_REVIEW_REQUIRED; независимое ревью проверяет смысл oracle и фактическое покрытие. Тесты не меняют source tree: временные БД/fixtures в tempfile, отчёты/raw evidence в os.environ["MVP1_ARTIFACT_DIR"] (отдельный каталог каждого из трёх прогонов); не писать generated evidence в git checkout. Контроллер сначала проверяет реальный assertion FAIL, затем green без изменения red-тестов. Для test-only работы разрешена временная мутация scoped production файла: контроллер восстановит его исходные байты перед green. Native subprocess обязан захватывать stdout/stderr и выдавать реальные ненулевые test counts (Go JSON, JUnit XML, unittest, pytest, TAP, GTest/Jest/CTest); python --version/echo/import без вызова продукта не являются runtime evidence.
