# ADR-BLUEPAD-001 — Интеграция BluePad через BLE Central

**Статус:** Принято
**Дата:** 2024-01-01

## Контекст

BluePad — внешний платёжный терминал, подключается к S3-устройству по BLE (Central role).
Протокол: проприетарный поверх GATT-характеристик (команды PURCHASE/REVERSAL/STATUS).
Альтернативы рассматривались: USB HID, UART/TTL. Выбран BLE — единственный поддерживаемый
физический интерфейс на BluePad при использовании вместе с ESP32-S3.

## Решение

S3 действует как BLE Central и инициирует подключение к BluePad по MAC/UUID.
Обмен данными через GATT characteristics: команда в Write, ответ в Notify.
Таймаут I/O: 30 секунд на каждый обмен.
Неудача соединения (DROP события 0E/01) = UNKNOWN (не FAILED).
Результат покупки подтверждается только через ответ команды 0x24 (PURCHASE_RESPONSE).

## Последствия

- Покупка считается COMMITTED только после получения корректного ответа 0x24.
- DROP события 0E/01 → состояние UNKNOWN → resolve по 0x24 на следующем старте.
- Новая покупка отклоняется если есть незавершённый реверс (storno-first инвариант).
- Отсутствие ответа в 30 с → таймаут → UNKNOWN, нет повторной попытки денежной команды.
- BLE Central роль требует явного SCAN + CONNECT перед каждой транзакцией если разрыв > 10 с.
