### NAP-N0 · P0 · Заморозка нормативного baseline (шаги)
1. Скачать консолидированный Н-18 НАП (актуальную редакцию) и посчитать SHA256; сравнить титульный перечень изменений (последний ДВ) с `…2025-05-23…pdf`.
2. Для каждого ДВ после 23.05.2025 из реестра (`evidence/nap-publication-register-2026-10-21/coverage.json`) выполнить поиск «Н-18|фискал|СУПТО|ИАСУТД» и записать результат в `docs/SUPTO/nap-baseline-<date>.md` (дата, ДВ, вывод «не затрагивает»/«затрагивает → NORM-xx»).
3. Прочитать первичные тексты: ДВ 115/2025 §34 (чл. 118 ЗДДС, консолидированная редакция), ДВ 82/2026 §2, ЗВЕРБ чл. 12, 13, 15.
4. Подписать baseline ответственным (юрист/бухгалтер) — поле в `docs/SUPTO/nap-baseline-<date>.md`.
- **Приёмка (автоматическая):** `bash scripts/check-nap-baseline.sh` — файл baseline существует, содержит SHA256 PDF, дату не старше 14 дней от даты релиза, нет строк `TODO|TBD`; exit 0.
- **DoD:** CDOD + запись в `MVP_GATES.md`.

### NAP-17 · P1 · Смена режима валюты (HIL + тест данных)
- **Шаги:** (1) сценарий на стенде: ФУ в режиме `1` → смена на `2/3` (выполняет производитель/сервис) → фото служебных бонов; (2) сохранить Z до/после (`nRep`, суммы); (3) backend: убедиться, что экспорт 18.x делит период по `bgEuroAdoption` и что накопленные суммы после превалютирования не удваиваются в агрегатах (тест на данных Z).
- **Тест:** `TestExportAcrossCurrencySwitchDoesNotDoubleCount` (`fiscal-backend/internal/domain/exports_test.go`), HIL `HIL-BC-EUR-02`.
- **Приёмка:** `cd fiscal-backend && go test ./internal/domain -run 'Export.*Currency|Euro' -count=1`; HIL-evidence по `docs/HIL_EVIDENCE_VERIFICATION.md`.

### NAP-18 · P1 · Сторно старого (лев) документа
- **Вопрос юристу NORM-16:** что печатать в сторно, если оригинал в лв: сумма в EUR по курсу или исходная; допускается ли сторно вообще после смены параметра на `3`.
- **Шаги до ответа:** запретить сторно документов с `fiscal_datetime < 2026-01-01` на уровне API с кодом `STORNO_PRE_EURO_BLOCKED_SPEC` (структурная ошибка, не 500); добавить тест на границе (31.12.2025 23:59:59 / 01.01.2026 00:00:00 Europe/Sofia).
- **Тест:** `TestStornoPreEuroDocumentRejectedUntilPolicy`; **Приёмка:** `go test ./internal/domain -run 'StornoPreEuro' -count=1`.

### NAP-19 · P1 · Округление и ЗВЕРБ
- Закрепить в ADR (`docs/decisions/ADR-MONEY-ROUNDING-001.md`, D-4): правило конвертации по ЗВЕРБ чл. 12–13 (первичный текст прочитать в рамках NAP-N0), единицы — целые евроценты, round-half-up на уровне **итоговой суммы** там, где закон требует, на строке — только если закон это допускает; примеры расчёта (таблица) и property-тест `ConvertThenSumEqualsSumThenConvert` с явными исключениями.
- **Приёмка:** `go test ./internal/domain -run 'Rounding' -count=1`; Kotlin `*Rounding*`; TS `jest -t rounding` (проверить команду pos-app) — три реализации дают идентичные результаты на общем наборе векторов `contracts/testdata/rounding.json` (создать).
