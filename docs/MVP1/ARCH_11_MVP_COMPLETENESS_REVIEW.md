## 6. Что остаётся открытым (честный список)
1. **Анализ статический**: ни один тест не запускался; W0-1 (базовая линия) — первое действие агента. Часть ссылок «файл:строка» сместится после правок.

Решение владельца **D-11** (SCOPE-01): входят ли они в MVP1. Если да — нужен отдельный проход.
3. **Contract-lock**: срез `docs/fiscal-contour-review-20261021` фиксирует `VERIFIED_FAIL` (расхождение runtime OpenAPI); задача DOC-003 обязана быть закрыта до любых изменений контракта (VG-07.3, VG-10.3).
4. **Вендор**: нет описания cmd 255 для BC-50, прошивки с параметром валюты и допълнения БИМ (DOC-V1/V2); нет Datecs Pay low-level (DOC-V3); нет Daisy SDK (DOC-V4); нет банковской сертификации (DOC-V6). До их получения VG-05 (часть), VG-09, VG-16, VG-17 — `BLOCKED_SPEC`.
