# ADR-SUPTO-003: FMIN-based Bulgarian UNP

`BG_UNP_V1` is issued only by `CountryIdentifierAuthority` from verified eight-character fiscal-device number, four-character operator code and fenced seven-digit sequence. Register UUIDs and POS-generated values are never regulatory identifiers. The separator remains a blocking policy decision until the approved byte representation is recorded in the country profile.
